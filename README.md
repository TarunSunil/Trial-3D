# Tarun Sunil Portfolio V2

First implementation phase for a spatial, liquid-glass portfolio.

## Run locally

1. Install Node.js 20.9 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the displayed local URL.

## Included in this phase

- Dark/light liquid-glass theme
- Responsive immersive scene layout
- Lanyard-style identity card hero
- Scroll-synchronised option-wheel section navigation
- Project, experience, skills, and contact scenes
- Reduced-motion support

The next phase can replace the CSS lanyard with React Three Fiber + Rapier and introduce true scene/camera choreography once the content and imagery are supplied.
